# 에이전트 운영 매뉴얼 (How to Operate the Agent)

> 대상 독자: **사람 엔지니어**. 이 리포는 에이전트 우선으로 운영된다 — 당신은 코드를 직접 쓰지 않고,
> 프롬프트와 피드백으로 에이전트를 통제한다. 잘 다루면 빠르고, 잘못 다루면 엔트로피가 쌓인다.
> 핵심 한 줄: **"리포에 적혀 있지 않으면 에이전트는 모른다."**(GP-10)

## 1. 황금 규칙 5가지
1. **맥락은 채팅이 아니라 리포에 둔다.** 중요한 결정·제약은 말로 하지 말고 `docs/`(design-docs 또는 exec-plans)에 적게 시켜라. 다음 세션의 에이전트는 이 채팅을 못 본다.
2. **목표를 주고, 단계를 받아라.** "X 를 어떻게 짜라"보다 "X 가 되면 무엇이 참이어야 하는가(수용 기준)"를 줘라. 계획은 에이전트가 `exec-plans/` 에 세우게 한다.
3. **검증 가능한 작업을 줘라.** "고쳐줘"가 아니라 "이 테스트가 통과하게/이 스냅샷이 이렇게 보이게". 에이전트는 [관측 하네스](observability-harness.md)로 스스로 확인한다.
4. **불변식을 가리켜라.** 새 규칙은 말로 반복하지 말고 [core-beliefs.md](../design-docs/core-beliefs.md) 에 GP-N 으로 추가하게 하라. 그래야 `golden-principles-check` 가 강제한다.
5. **작게, 자주, 리뷰 가능하게.** 거대한 한 방 PR 대신 작은 PR. 자율 루프(Ralph)도 작은 변경에서 가장 잘 돈다.

## 2. 좋은 프롬프트 vs 나쁜 프롬프트
| 나쁨 (모호/맥락 외부) | 좋음 (검증 가능/맥락 내부) |
|---|---|
| "테넌트 격리 좀 손봐줘" | "GP-1 위반 여부를 `golden-principles-check.ps1` 로 점검하고, 누락된 서비스 쿼리에 `(company_id, workplace_id)` 필터를 추가해 `test_cross_contamination.py` 를 그린으로 만들어줘" |
| "이거 왜 안 돼?" | "`./scripts/run-local.ps1` 로 띄운 뒤 `capture-ui.ps1` 로 스냅샷 찍고, 콘솔/네트워크 로그에서 원인을 찾아 exec-plan 에 기록해줘" |
| "문서도 업데이트해줘" | "코드 변경에 맞춰 `doc-drift-check.ps1` 를 돌리고 드리프트 난 문서만 갱신해줘" |

## 3. 피드백 주는 법
- **방향 수정은 빠르게.** 에이전트가 엉뚱한 길로 가면 즉시 중단(Esc)하고 어디서 갈라졌는지 짚어줘라 — 끝까지 두고 통째로 버리지 말 것.
- **근본 원인을 교정하라.** 같은 실수가 반복되면 그건 *프롬프트/문서의 결함*이다. 일회성 지적 대신 해당 규칙을 `core-beliefs.md` 나 `CLAUDE.md` OVERRIDE 에 박아라.
- **칭찬도 신호다.** "이 방식 좋았다"를 명시하면 에이전트가 그 패턴을 메모리/문서에 굳힌다.
- **거부 ≠ 재시도 요청.** 도구 호출을 거부하면 같은 걸 다시 하지 말고 다른 접근을 제시하라는 뜻으로 받아들인다.

## 4. 라이프사이클 한 바퀴 (사람의 개입 지점)
```
[사람] 목표/수용기준 제시
   → [에이전트] exec-plan 작성 ──(사람 승인)──┐
   → [에이전트] 구현 + 자가 검증(테스트/스냅샷/메트릭)
   → [에이전트] PR 오픈 (agent-pr-loop, mode=apply 는 사람이 트리거)
   → [에이전트 리뷰어] 리뷰 코멘트 (agent-review)
   → [에이전트] 수정 푸시  ⟳ (리뷰 통과까지)
   → [사람] 머지 결정 ★ (자동 머지 없음 — 항상 사람 게이트)
   → [doc-gardening] 문서/스키마 드리프트 동기화
```
★ 표시가 **사람이 반드시 개입하는 지점**이다. 나머지는 에이전트가 자율로 돈다.

## 5. 자주 쓰는 명령 (사람용)
```powershell
# 에이전트에게 작업 1바이클 돌리게 하기(로컬, 기본 dry-run)
./scripts/agent/ralph-loop.ps1 -Task "docs/exec-plans/2026-06-16-xxx.md"
./scripts/agent/ralph-loop.ps1 -Task "..." -Apply     # 실제 브랜치/PR 까지

# 자가 검증 도구
./scripts/observability/capture-ui.ps1 -Url http://localhost:5173   # UI 스냅샷+DOM
./scripts/gardening/doc-drift-check.ps1                              # 문서 드리프트
./scripts/gardening/golden-principles-check.ps1                     # 황금 원칙 점검
```

## 6. 안티패턴 (하지 말 것)
- 채팅에만 있는 "구두 합의"로 일하기 — 다음 세션엔 증발한다.
- `generated/` 를 손으로 고치기 — 다음 생성에 덮어쓰여진다.
- 자율 루프에 자동 머지를 붙이기 — 비가역 행동은 항상 사람 게이트(현 스켈레톤은 의도적으로 막아둠).
- 거대한 PR 한 방 — 리뷰·롤백이 불가능해진다.
